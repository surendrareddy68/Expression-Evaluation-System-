Expression Evaluation System Using Stack in C:

Project Description:

The Expression Evaluation System is a C programming project that evaluates arithmetic expressions using the Stack data structure.

Objectives:

- To understand the Stack data structure.
- To implement stack operations in C.
- To evaluate arithmetic expressions.
- To understand operator precedence and parentheses.

Features:

- Supports addition, subtraction, multiplication, and division.
- Supports parentheses.
- Follows operator precedence.
- Accepts multi-digit positive integers.
- Displays the calculated result.

Technologies Used:

- Programming Language: C
- Data Structure: Stack
- Development Tool: OnlineGDB / C compiler

Real-World Applications:

1. Calculators: Evaluates arithmetic expressions according to operator precedence.
2. Compiler Design: Helps process arithmetic expressions in programming languages.
3. Spreadsheet Software: Stack-based expression processing can help evaluate formulas in spreadsheet applications.

Sample Input:

2+3*4

Sample Output:

EXPRESSION EVALUATION SYSTEM
Enter expression: 2+3*4
Result = 14

How It Works:

1. Reads an arithmetic expression from the user.
2. Stores numbers and operators in separate stacks.
3. Checks operator precedence.
4. Performs calculations using stack operations.
5. Displays the final result.

Limitations:

- Supports positive integer operands.
- Division uses integer arithmetic.
- Some invalid expressions may not be handled correctly.

Conclusion:

This project demonstrates the practical use of the Stack data structure for evaluating arithmetic expressions in C.
